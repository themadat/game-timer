# Dune: Imperium — Uprising setup reference

Source: user-supplied `DUNE_IMPERIUM_UPRISING_RULEBOOK.pdf`, © 2023 Dire Wolf Digital. Page references below are the PDF's printed pages. This is a separate game from Dune (2019).

## Loaded into Game Timer

- **Player colors:** red, blue, green, yellow, shown in setup on p. 5. Display hex values approximate the printed components.
- **First player:** use Objective cards appropriate to the player count (1–3P or 4/6P); deal randomly. The player whose card shows the First Player marker starts (pp. 4–5). Select that person in setup; do not roll another starter.
- **Turn order:** clockwise from the first-player marker (p. 7). With names entered clockwise, selecting first player rotates the roster while preserving adjacency.
- **Other timers:** Combat, Makers, Recall, Scoring. These are optional timing buckets, not an automated rules engine.
- **Player range:** 1–4 for the standard game. Solo and two-player games require the separate Rivals supplement. Six-player teams require their own supplement (p. 5); the main rulebook alone does not establish that mode's full seating or first-player rules. Five players are not a supported count in this book.
- **Duration, complexity and recommended counts:** left unknown; this PDF does not supply catalog ratings or a duration range.

## Leaders and influence factions

Choose leaders or deal them randomly. Prefer one-icon leaders for a first game; more icons indicate greater strategic complexity. Shaddam Corrino IV requires the CHOAM module (p. 4). Using different Houses is a thematic recommendation, not a mandatory restriction (p. 2).

Leaders are independent of player colors. Emperor, Spacing Guild, Bene Gesserit and Fremen are shared influence tracks (pp. 4, 6), not four exclusive player factions. The preset therefore uses plain player colors rather than assigning these factions to players. The main book does not enumerate all leader names in extractable text, so no speculative leader roster is loaded.

## Session timing and round changes

Rounds have five phases: Round Start, Player Turns, Combat, Makers and Recall (p. 7).

During Player Turns, each turn is either an Agent turn or a Reveal turn. Once someone reveals, skip them for the remainder of that phase. When everyone has revealed, proceed to Combat (p. 7).

Combat Intrigue starts at the first-player marker and continues clockwise among players with units in the Conflict. Passing once does not eliminate a player: continue until all participating players pass consecutively, then resolve Combat (p. 14).

After Makers, Recall checks for the end of the game. If continuing, recall Agents and pass the first-player marker one seat clockwise (p. 15).

Game Timer's Next player control follows the configured fixed roster. Select player cards manually to skip revealed players, time Combat separately, and start the next round with the new marker holder. The app does not infer phases, reveals, units, or round boundaries from timer turns. A full-order shuffle is a one-time setup option when table position does not matter; it is not a Uprising round rule.

## Scoring reference

Endgame is triggered at Recall when someone has at least 10 VP or the Conflict deck is empty. Resolve Endgame Intrigue first, then compare total VP. Break ties by spice, then Solari, then water, then garrisoned troops (p. 15). Enter final placements manually.

In four-player setup, begin at 1 VP; otherwise begin at 0 VP (p. 5). This is a board setup reminder, not a timer score adjustment.
