# Verification

Choose checks for changed behavior and shared-code risk. Documentation-only edits need `git diff --check`, not app tests or a preview.

## Automated

```sh
node --test tests/*.test.mjs
for file in assets/js/*.js assets/js/core/*.js assets/js/data/*.js assets/js/features/*.js sw.js; do node --check "$file" || exit 1; done
node -e "for (const f of ['manifest.webmanifest','manifest-dark.webmanifest']) JSON.parse(require('fs').readFileSync(f,'utf8'))"
git diff --check
```

`tests/game.test.mjs` covers player-count fit, placements with ties, totals and awards, state normalization, and BGG clipboard parsing/catalog override persistence. `tests/boot.test.mjs` checks ordered scripts, versioned assets, and that every referenced file exists. `tests/pwa.test.mjs` covers the update flow. `tests/vibe-check.test.mjs` checks table matching against exhaustive search, accepted choices and player limits, host passcode rejection/cooldown, relocking, private handoffs, and clearing.

Without Node, `osascript -l JavaScript` can syntax-check files with `new Function(source)`.

Serve the repository with a static development server and open `tests/bgg-preview.html` for browser-native XML parser checks against the BGG fixtures (no installed packages required).
Use a normal browser for live BGG requests; BGG may reject preflights from headless browsers.
